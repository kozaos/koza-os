# KozaOS

[English](README.md) · [Türkçe](README.tr.md)

Eski bilgisayarına yeniden hayat ver. Linux bilmeyen ev kullanıcıları için Arch Linux tabanlı bir dağıtım.

İki sürüm:

- **KozaOS XFCE** — çok eski makineler için (X11, LightDM)
- **KozaOS KDE** — biraz daha yeni eski makineler için (Wayland, SDDM)

Durum: geliştirme aşamasında, henüz indirilebilir ISO yok.

Ölçülen RAM kullanımı ve açılış süreleri: [docs/measurements.md](docs/measurements.md)

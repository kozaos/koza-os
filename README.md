# KozaOS

[English](README.md) · [Türkçe](README.tr.md)

Give an old computer a new life. An Arch Linux based distribution for home users who don't know Linux.

Two flavors:

- **KozaOS XFCE** — for very old machines (X11, LightDM)
- **KozaOS KDE** — for somewhat newer old machines (Wayland, SDDM)

Status: in development, no downloadable ISO yet.

Measured RAM use and boot times: [docs/measurements.md](docs/measurements.md)
